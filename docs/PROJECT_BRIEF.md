# 项目说明

## 产品定位

“成品工坊”是临时品牌名。产品定位为数字服务工作室、服务商城和运营管理后台，主要帮助客户购买商家视觉、网站开发、办公资料和数字产品。

## 第一阶段目标

1. 完成响应式前台首页、服务、套餐、案例与详情页。
2. 完成服务端规则报价、需求提交、管理员登录和数据持久化。
3. 完成服务、套餐、需求、订单、案例、品牌和网站设置管理。
4. 完成产品母版、多平台内容草稿、一键复制和素材导出。
5. 所有未接入的外部平台显示真实连接状态，不使用模拟成功结果。

## 视觉方向

- 暖灰背景 `#F7F7F4`
- 墨黑标题 `#151619`
- 主按钮 `#C94018`
- 白色卡片、浅灰边框、克制阴影
- 现代数字工作室与轻商城风格
- 手机端优先，避免廉价促销和过量炫光效果

## 集成原则

- GitHub：网站自己的 GitHub App，默认只读，写入在分支中进行并通过 PR 审核。
- Codex：用于代码修改、检查与测试；与网站进程隔离运行。
- 闲鱼、小红书、快手：依据账号取得的官方权限逐项启用。无权限时提供草稿、素材导出和人工发布回填。
- 客户文件、订单与隐私数据不得存储在 GitHub 仓库。
