# 成品工坊｜数字服务商城

面向本地商家、创业者和个人的一站式数字成品交付平台。

计划包含：

- 商家视觉、网站与系统、办公成品、数字产品四类服务
- 服务详情、规则报价器、需求提交和订单管理
- 管理后台、品牌档案、案例与素材管理
- GitHub 项目导入、内容草稿和平台连接状态
- 后续接入 Codex 与获得官方授权的内容平台

## 开发方式

- `main`：稳定版本
- `dev`：日常开发版本
- 新功能：从 `dev` 创建功能分支，测试后通过 Pull Request 合并

完整开发规格见 [docs/PROJECT_BRIEF.md](docs/PROJECT_BRIEF.md)。

## 安全要求

不要提交 `.env`、API 密钥、客户资料、数据库、上传文件、日志或第三方访问令牌。外部平台未获得正式授权前，仅显示未连接或提供人工导出流程。
